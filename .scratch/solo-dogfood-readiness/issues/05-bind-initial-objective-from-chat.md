# 05 — Bind the initial objective from ordinary chat

**What to build:** Allow the host agent to translate an unambiguous conversational objective into the existing packet-bound authorization seam and durably bind it to the current project state without requiring the human to operate Forge.

**Blocked by:** 04 — Activate Solo Cooperative through the start and next journey.

**Status:** ready-for-agent

- [ ] One ordinary chat objective becomes a typed proposal containing outcome, constraints, unacceptable outcomes, and open uncertainty.
- [ ] The accepted proposal is bound to the current action packet, project snapshot, carrying principal, and cooperative provenance.
- [ ] The host agent completes the Forge interaction; the human edits no YAML or JSON and runs no Forge command.
- [ ] Material ambiguity produces one concise Decision Request instead of guessed acceptance.
- [ ] A fresh workflow-next readback derives progression from the durable ledger record.
- [ ] Cooperative acceptance cannot satisfy a claim that explicitly requires strict external origin.
