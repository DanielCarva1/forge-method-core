# 09 — Preview a Governed Promotion

**What to build:** Provide a read-only promotion preview that binds isolated agent work to the accepted objective, exact source and destination snapshots, diff, declared write set, claims, and required evidence before canonical mutation is possible.

**Blocked by:** 08 — Admit cooperative evidence without claiming independence.

**Status:** ready-for-agent

- [ ] Previewing a worktree promotion performs no canonical repository mutation.
- [ ] The preview binds the exact source worktree and canonical destination snapshots.
- [ ] The complete diff and write set are deterministic and content-addressed.
- [ ] Objective coverage, claim coverage, evidence status, conflicts, and unresolved gaps are visible in the preview.
- [ ] A changed source, destination, objective, or evidence set invalidates the old preview.
- [ ] Out-of-scope or destructive effects are identified before apply authority can be prepared.
