# 07 — Enforce the Agent Autonomy Boundary

**What to build:** Route reversible development work to the agent by default and reserve human Decision Requests for product-objective changes, material trade-offs, material risk acceptance, and irreversible or external effects.

**Blocked by:** 05 — Bind the initial objective from ordinary chat.

**Status:** ready-for-agent

- [ ] Research, planning, implementation strategy, local reversible edits, tests, documentation, retries, and evidence generation do not require human approval.
- [ ] Each of the four irreducible human-decision classes produces a typed Decision Request with rationale and consequences.
- [ ] Merely changing tactics, files, tests, or implementation order does not become a human decision.
- [ ] Publication, deployment, production mutation, secret use, and destructive external effects remain explicitly human-gated.
- [ ] Acceptance scenarios distinguish legitimate autonomy from an agent changing the accepted objective.
