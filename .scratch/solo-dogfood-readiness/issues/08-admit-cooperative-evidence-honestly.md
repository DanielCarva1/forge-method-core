# 08 — Admit cooperative evidence without claiming independence

**What to build:** Admit provenance-bearing representative execution and authoritative readback for solo-scoped claims while explicitly withholding independent-review, independently separated runtime, human-presence, and compliance claims.

**Blocked by:** 07 — Enforce the Agent Autonomy Boundary.

**Status:** ready-for-agent

- [ ] Current, subject-bound cooperative evidence can satisfy a claim whose policy permits `cooperative_same_owner`.
- [ ] The same evidence cannot satisfy claims requiring independent reviewer or trusted-runtime separation.
- [ ] Fabricated results, stale observations, wrong subjects, mismatched digests, and missing readbacks fail closed.
- [ ] Evidence projections state both what the evidence proves and what it does not prove.
- [ ] Representative execution is distinguished from artifact presence or command exit status alone.
- [ ] Rejected evidence remains traceable without affecting the supported claim state.
