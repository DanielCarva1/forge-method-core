# Triage labels

The engineering skills use these canonical roles. Map them to the labels that
actually exist in this repository.

| Canonical role | GitHub label | Use |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required before planning |
| `ready-for-agent` | `ready-for-agent` | Approved and fully specified for agent implementation |
| `ready-for-human` | not configured | Do not create or apply without user approval |
| `wontfix` | `wontfix` | The work will not be actioned |

Product Journey Guidance tickets are written by the agent after product
discussion. Apply `ready-for-agent` only after the user accepts the proposed
ticket and its dependencies.

Do not create missing labels as a side effect of publishing an issue. Ask first
when a genuinely new label is required.
