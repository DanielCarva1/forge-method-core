# Forge Desktop 0.1.82 alpha

## One creative space, across the app

- Início, Explorar, Meus projetos and Minha conversa now share a local cinematic
  scene, warm reading colors, restrained glass and a compact navigation rail.
- The selected destination keeps its name on desktop. Other destinations and
  secondary tools show names on hover or keyboard focus; Escape dismisses them.
  The main actions still have short, visible names.
- Original Forge category artwork remains intact. Recent projects use clearer
  cards and an explicit empty state, not invented projects or progress.
- Appearance and stronger contrast are available from every screen. The comfort
  menu closes with Escape or a click outside; narrow layouts keep it on screen.
- Tools for the selected result are grouped beside it. **Pedir mudança** prepares
  a draft in the existing conversation; it does not send a message. Expanding,
  showing the file, saving a copy and refreshing use the existing handlers.
- Existing movable panels, project creation/opening, saved conversations,
  permissions and protected preview remain the same underlying flows.

## Verification and limits

Focused browser checks cover the production CSP, four routes and active/focus
state, day/night, icon names and Escape, comfort dismissal, contrast controls,
360/700px layout, enlarged text, category search/draft, empty/recent/filter states
and floating-panel interactions. Installed isolated native checks passed those
screen/panel interactions, actual Core project creation, file discovery/selection,
protected HTML preview and change drafting without Send. Browser project cards are presentation fixtures,
not native/Core proof. Exact native and installer evidence belongs to the latest
Desktop README checkpoint.

This package does not claim a complete visual redesign, screen-reader certification,
a clean-machine sign-in test, or better agent output. The result in acceptance
captures is an owned disposable local HTML test file, not a user project or a
model-generated delivery. No model turn is required for this presentation package.

Core remains 0.13.4. Windows alpha is unsigned; updates are manual. Protected HTML
preview is noninteractive, and saving a copy exports one file, not a complete site.
Mobile/remote access is deferred. No new UI framework, native permission, service,
account, project registry or process gate is added.
