# Forge Desktop 0.1.81 alpha

## Arrange your working space

- Conversation, result, progress and project are the same existing panels,
  now movable, resizable, collapsible and reopenable on wide desktop screens.
- Drag by the title bar or use the move/resize control and keyboard arrows.
  Snap to either side, expand the active panel or choose **Organizar espaço**.
- Conversation remains the main initial surface. When a result is available,
  organizing places conversation and result side by side; context stays on demand.
- Geometry is remembered on this device. Small/coarse-pointer screens and
  enlarged text retain the simpler existing layout.
- A local cinematic scene, warm reading surfaces and restrained glass start
  the accepted visual direction. Names for secondary window controls appear
  on hover or keyboard focus. No decoration service or new UI framework.
- The composer keeps its Send action inside a snapped half-width conversation;
  attaching a reference is a compact labeled-on-focus icon. Existing permission
  disclosure and explicit sending remain intact.

## Verification and limits

Focused geometry and headless browser checks cover movement, resizing, drag
cancellation, keyboard, snap, focus, collapse/reopen, organize, persistence,
narrow navigation and enlarged-text fallback under the current CSP. Browser
project setup is a presentation fixture, not backend/native proof.

Installed isolated native acceptance covered an actual Core-created project,
local HTML preview and those panel interactions; snap Send fits and the scene
does not introduce horizontal page overflow. Exact installer receipt belongs
to the latest Desktop README checkpoint. Window actions did not send, connect,
disconnect or stop the agent; the draft was preserved. No new model turn was needed to
validate this presentation-only change. Full-screen polish, contextual icon
tools and the remaining UX roadmap are still in progress; this is not a claim
that the entire cinematic redesign or physical accessibility is complete.

Core remains 0.13.4; mobile is deferred. Unsigned Windows alpha, manual updates
and protected noninteractive preview limits remain. No network server, new
account flow or altered project governance is introduced.
