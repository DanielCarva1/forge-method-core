# Forge Desktop 0.1.77 alpha

- “Pular para o conteúdo” mantém a tela em que você está.
- Uma pergunta pendente aparece na navegação, mesmo quando você está vendo
  Resultado, Andamento ou Projeto. Sua tela não muda sozinha.
- Ao voltar para Conversa, o teclado vai para a pergunta. Enviar, interromper
  ou passar para a próxima pergunta mantém um ponto de foco útil.
- Atualizações da lista de arquivos preservam sua posição pelo teclado.
- Mapa de conclusão do produto consolidado em `PRODUCT_STATUS.md`.

## Limitações

Alpha Windows sem assinatura; atualização instalando o novo pacote.
Não inclui acesso remoto pelo celular, verificação de acessibilidade em telefone
físico/leitor de tela, nem autenticação completa em máquina limpa. Perguntas
foram verificadas com servidor Codex simulado, não uma chamada real do modelo.
Pastas com junction externo ainda podem falhar ao preparar o registro do motor.
Não altera Core 0.13.3, não envia mensagens automaticamente nem modifica os
arquivos do projeto. O mapa não declara o produto completo.
