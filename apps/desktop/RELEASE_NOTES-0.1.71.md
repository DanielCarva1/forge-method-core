# Forge Desktop 0.1.71 alpha.1

**Start with an idea, not a folder.** From Home, Explore, or My Projects, write an idea and use **Enviar e criar projeto**: the app creates a new folder under Documents → Projetos Forge, prepares it with Forge, and sends that one message to Codex. Choosing an existing or custom folder remains optional. If setup fails, the draft stays in place and is not sent later automatically. Changing the draft or leaving the screen cancels the pending first send. Preparing a project from the project card still does not send a message.

This installer includes Forge Core 0.13.3 and lighter Start Forge guidance. Small, reversible local work no longer requires extra protocol closeouts just to proceed. The project record puts the confirmed objective and next step first, keeps lifecycle details optional, and shows a recorded direction even when no next work has been defined. The conversation shows plain-language Codex activity without claiming a percentage. The file-access notice is still visible but no longer styled as a dominant alert. Navigation, local preview and unsent change requests remain available.

## Verification and limits

Focused browser tests passed for first-send ownership, draft preservation, the record state, and the access notice. One real Codex first-send journey passed on the installed 0.1.70 build with a disposable **custom folder**: one click prepared the project, sent once, created `site/index.html`, opened the protected preview, and prepared an unsent change request. The 0.1.71 candidate was installed over 0.1.70; its four entry screens and a disposable loaded-project preview were captured in the native WebView without another Send. Default-folder creation passed natively and its combined one-click Send passed in a browser double, but a single real default-folder Send was **not** exercised. The broad browser suite still has outdated expectations from the changed first-use flow; it is not a passing gate for this candidate. No productivity or cost improvement is inferred from one real project.

This is an unsigned Windows x64 alpha, updated manually with the NSIS installer. First login on a clean device, manual screen-reader use, a physical mobile device, and publishing the created project online were not verified. The Forge preview is local and protected; using a page interactively in a normal browser is a separate, explicit action. Do not treat an agent's suggested question as a decision accepted by the user.
