Versão e atualizações

Verificando a versão instalada…

Esta versão alpha não se atualiza sozinha. Na página de versões, procure a versão mais recente chamada Forge Desktop com número maior que o instalado acima. Baixe o instalador de Windows Forge_…_x64-setup.exe, feche o aplicativo e instale por cima. Não escolha “Source code” nem uma versão do Forge Core.

Se o navegador não abrir, copie este endereço: https://github.com/DanielCarva1/forge-method-core/releases?q=desktop
