# Forge Desktop 0.1.83 alpha

## More room to read, less visual noise

- Agent responses use an open reading column; your messages remain distinct.
  Warmer text, longer line spacing and readable code, quote and table surfaces
  improve the existing conversation without replacing its engine or history.
- Andamento emphasizes the objective and next step. Detailed records, phases,
  pending choices and original direction remain available in their existing
  disclosures. No progress or decision is invented.
- Conversation options are a small anchored menu, dismissed with Escape,
  clicking outside or leaving it with the keyboard. Secondary refresh is a
  named-on-focus icon; primary actions retain visible names.
- Drafts reflow when the floating window changes width, without sending or
  losing their text. Window controls, permission warnings and uncertain-send
  handling remain owned by their existing modules.
- Questions show the selected option clearly. Login and confirmation surfaces
  remain explicit and readable, with quieter surrounding glass/backdrops.
- Corrects light-theme nested surfaces that reused the dark scenery background.

## Verification and limitations

Focused Chromium checks exercise the production CSP, day/night nested-text
contrast, conversation-menu focus/dismissal, draft reflow, floating controls,
question selection/free text and narrow enlarged layouts. Conversation, record,
questions and login samples are **presentation fixtures**, not real Codex
responses, recorded decisions or authenticated sign-in. The native milestone
and exact installed/public installer evidence are recorded in the Desktop README.

This is a presentation package, not a claim that all UX is finished or that
accessibility or first-provider login on a clean machine has been certified.
No model turn or user account change is required. Core remains 0.13.4.
Windows alpha remains unsigned with manual updates; local HTML previews are
protected/noninteractive, and saving a copy exports one file, not an entire site.
Mobile/remote access remains deferred. No framework, native permission, service,
new account, project registry or mandatory governance step is added.
